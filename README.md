# Уведомления об отключении света — группа 3.1

Проект проверяет официальный сервис АТ «Миколаївобленерго» каждые пять минут и отправляет push-уведомление через [ntfy](https://ntfy.sh/) примерно за час до возможного отключения.

## Подключение телефона

1. Установите приложение ntfy на Android или iPhone.
2. Добавьте секрет `NTFY_TOPIC` в **Settings → Secrets and variables → Actions** этого репозитория.
3. В приложении ntfy подпишитесь на значение, сохранённое в `NTFY_TOPIC`.
4. Для теста откройте **Actions → Уведомления об отключении света → Run workflow**, включите «Отправить тестовое уведомление» и запустите проверку.

Название канала должно быть длинным и случайным: на бесплатном ntfy оно работает как пароль. Не добавляйте его в публичные файлы репозитория.

## Изменение группы

Откройте `config.json`, нажмите значок карандаша и замените значение `group`, например на `4.2`. Поддерживаются группы от 1.1 до 6.2. После сохранения GitHub автоматически проверит новую настройку.

## Как это работает

- Источник: https://off.energy.mk.ua/api/v2/schedule/active
- Проверка: каждые пять минут через GitHub Actions.
- Предупреждение: ориентировочно за 35–70 минут, поскольку бесплатные задания GitHub иногда запускаются с задержкой.
- Повторы одного уведомления блокируются кэшем GitHub Actions.
- Передаются только номер группы, время отключения и ссылка на официальный сайт.

## Ограничение бесплатного варианта

GitHub может остановить запланированные задания публичного репозитория после 60 дней без изменений. В таком случае откройте вкладку Actions и нажмите кнопку включения workflow.
